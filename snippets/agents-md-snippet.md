# AGENTS.md 代码片段（兜底安装：给没有技能机制的 Agent 用）

> 适用：Codex / Cursor 及其他不加载 SKILL.md 的 Agent。
> 把下面整段贴进你的 `AGENTS.md`（或等价的全局规则文件：`.cursorrules`、`CLAUDE.md` 等）。
> 先把仓库克隆到一个固定位置（示例用 `~/.refinery-skill`，路径可自定）：
>
> ```bash
> git clone https://github.com/istoolsfox/refinery-skill.git ~/.refinery-skill
> ```

## 代码优化流程（refinery 精炼厂）

当用户要求优化代码、清理死代码、删除无用代码、代码体检、精炼、重构、优化链路时，执行以下流程：

1. 先完整读取 `~/.refinery-skill/skills/refinery/SKILL.md`（路径不同则用实际克隆路径），严格按其中的六步流水线执行：侦察 → 定档 → 基线 → 四道工序（表层清零/死代码/原则体检/链路优化）→ 对抗自查 → 优化报告。
2. 细则文件在同目录 `reference/` 下（测试纪律/三模式/死代码证据链/对抗自查/哲学文件模板），按 SKILL.md 的指引**按需读取**，不要整包加载。
3. 硬性约束（不得跳过）：
   - 动代码前先跑全量测试建立基线；基线红必须停下报告；
   - 禁止修改/删除/跳过既有测试；声称"通过"必须附被测命令自己的退出码（警惕管道陷阱：`cmd | tail` 后 `$?` 是 tail 的）；
   - 判定"死代码"必须过四步证据链（全仓搜索→动态调用排查→公共 API 边界→框架魔法），工具输出只是候选名单；
   - 别人的仓库默认只出体检报告、不动代码；要改则收敛上游风格，行为变更先去 issue 问 intended；
   - 说"没人用""更快"必须有证据或测量，拿不准标"未确认"。
